# docs/

Durable reference only. The website (Astro, deployed by `.github/workflows/site.yml`) is in
`site/`. `docs/solutions/` is the compound-engineering learnings store, and
`.claude/rules/` cites it by path.

Plans, specs and in-flight work are tracked in worktrack workspace `tman`. A plan that an open
task cites is committed under `docs/plans/` while the task is open, and removed once the work
lands.
